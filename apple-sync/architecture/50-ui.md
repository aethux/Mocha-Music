# 50. UI, navigation, player

## Navigation

`ui/screens/Screens.kt` defines four main destinations — Home (`home`), Search (`search_input`),
Library (`library`), Settings (`settings`) — with animated icons, plus route strings for everything
else built in `ui/screens/NavigationBuilder.kt`. `MainActivity` hosts a single activity; the tabs and
the bottom bar are Compose.

Notable destinations, by file:

| Screen | File |
|---|---|
| Home | `ui/screens/HomeScreen.kt` (+ `ui/component/` shelves, hero cards, gacha/discover items) |
| Search | `ui/screens/search/SearchScreen.kt`, `OnlineSearchScreen`, `LocalSearchScreen`, `GenreScreen`, `suggestions/` |
| Library | `ui/screens/library/*` (songs, albums, artists, playlists, imported, cached, local) |
| Album / artist | `ui/screens/AlbumScreen.kt`, `ui/screens/artist/*` |
| Playlists | `ui/screens/playlist/LocalPlaylistScreen`, `OnlinePlaylistScreen`, `CachePlaylistScreen`, `AutoPlaylistScreen`, `TopPlaylistScreen` |
| Settings | `ui/screens/settings/*` |
| Stats / recap | `ui/screens/recap/StatsScreen.kt` (+ story-style recap) |
| Onboarding | `ui/screens/setup/*` (welcome art, permissions, blur probe, import step) |
| TV | `ui/tv/*` (own activity, focus-based UI) |
| Car | `car/*` (Media3 Car App templates) |

## Settings tree

`ui/screens/settings/MochySettingsScreen.kt` + `SettingsPane.kt` render a searchable list of rows
(about 200 preference keys). Categories include: appearance, customisation, audio lab, playback, now
playing, modules, integrations, storage, app behaviour, devices/link, proxy, offline, data saver,
floating lyrics, and a "larp mode" joke feature. `SettingsRows.kt`, `SettingsRecommendations.kt` and
`SettingsEntry.kt` are the building blocks.

## Player styles

The player is not one screen but a set of styles, chosen in customisation (`PlayerStyle`,
`PlayerBackgroundStyle`, `PlayerCoverStyle`, `PlayerButtonsStyle` in `constants/`):

| Style | File |
|---|---|
| Flagship | `ui/player/flagship/` |
| Classic | `ui/player/` (default transport) |
| Turntable | `ui/player/` vinyl visuals (`DiscGeometry`), widget in `widget/TurntableWidgetReceiver` |
| Poster / Timeline | `ui/player/` variants |
| Lyrics-first | `ui/player/` lyrics layouts, `LyricsPosition` |
| Bedside | `ui/player/bedside/` |
| Video | `ui/player/video/` (YouTube video, DASH, frame sampling, ambient light) |
| iPod | `ui/player/ipod/` (wheel, cover flow) |

Shared pieces: `ui/player/models/` (transport state), `ui/player/styles/` (skin-driven drawing),
`ui/player/studio/` (the layout studio), `ui/player/customize/`, `ui/player/menu/`,
`ui/player/info/` (about this song/artist, stats), `ui/player/share/` (share cards and video export).

## Customisation and theming

- `ui/theme/` — artwork palette extraction (`ArtworkPalette`, `CoverThemeColor`,
  `PlayerColorExtractor`), look fonts.
- `modules/skin/` — the module "look" system: `SkinProgram`, `SkinPlayer`, `SkinGlass`, pages,
  shaders, keyframes, states/events. A look can restyle the player, the bar and settings pages.
- `constants/` — enums for every style choice (HomeStyle, PlaylistStyle, LyricsMotion, IpodTheme…).
- `utils/AppIcons.kt` + the ~50 `activity-alias` entries switch the launcher icon at runtime.
- `ui/screens/setup/onboarding/BlurCapability.kt` probes whether the device can afford blurs and
  warns (it caught the emulator on first run).

## Other surfaces

- Widgets: `widget/MochyWidgetManager`, `MusicWidgetReceiver`, `TurntableWidgetReceiver` (Glance).
- Floating lyrics: `floating/` (overlay pill, reading settings, window management).
- Video: `ui/player/video/` plus `utils/VideoStreams`, `VideoTrack`.
- Share/export: `ui/player/share/` renders cards and video, `ui/player/share/song/export/`
  (`OffscreenFrames`, `ShareEncoders`, `ShareExportJob`).

## Accessibility and localisation

`i18n/AppLanguage.kt`, `ui/screens/settings/AppLanguageSheet.kt`, Crowdin config (`crowdin.yml`),
`l10n_main` branch upstream. Strings live in `app/src/main/res/values/strings.xml` plus ~40 locales.

## Notes for the sync work

- The Library tab is the natural home for "Apple by default": `LibraryTabs` / `LibraryScaffold` decide
  which tabs exist and their order.
- The playlist menu (`ui/menu/PlaylistMenu.kt`, `PlaylistScreenMenus.kt`) already has a "re-sync"
  entry wired to `PlaylistResync` — an Apple sync row belongs beside it.
- Song menus (`ui/menu/SongMenu.kt`, `YouTubeSongMenu.kt`, `SelectionSongsMenu.kt`) are where a
  "match on Apple Music" action goes.
